# GA Helper 3.0

Google Ads 素材填充辅助 Chrome 扩展，用于把广告创作模板拆分为标题、描述、站内链接、宣传信息和结构化摘要等模块，方便在 Google Ads 页面中整理和填充素材。

## 功能特性

- 支持在 `ads.google.com` 页面注入辅助面板
- 支持拆分完整广告素材模板
- 支持广告标题、广告描述、站内链接、宣传信息、结构化摘要模块
- 支持字符数检查和超限提示
- 支持把 AI 生成内容粘贴后自动拆分
- 支持生成用于广告素材创作的提示词
- 支持本地缓存拆分内容，便于恢复继续编辑

## 安装方式

1. 下载或克隆本仓库到本地。
2. 打开 Chrome，进入 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目所在文件夹。
6. 打开 Google Ads 页面后使用扩展入口和页面内辅助面板。

## 文件结构

```text
.
├── manifest.json   # Chrome 扩展配置
├── content.js      # 注入 Google Ads 页面的主脚本
├── popup.html      # 扩展弹窗页面
├── icon.png        # 扩展图标
├── TASKS.md        # 后续优化任务记录
└── README.md       # 项目说明
```

## 使用说明

1. 在 Google Ads 相关页面打开扩展。
2. 使用页面内辅助面板粘贴完整广告素材模板。
3. 点击拆分功能，把内容拆为标题、描述、站内链接等模块。
4. 检查字符数和数量是否符合 Google Ads 要求。
5. 根据面板提示手动填充或辅助填充到 Google Ads 对应输入框。

## 注意事项

- 本扩展仅匹配 `ads.google.com` 页面。
- 不直接调用 ChatGPT 网页或 OpenAI API。
- Google Ads 页面结构可能更新，如遇到输入框无法识别，需要调整 `content.js` 中的 selector 配置。
- 当前仓库包含的是未打包源码，适合开发者模式加载使用。
